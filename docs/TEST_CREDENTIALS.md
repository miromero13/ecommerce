# Test Credentials

This document contains all pre-seeded user accounts generated by `backend/seed.py` for testing and evaluation.

> **Login Instructions:**
> * Go to `http://localhost:4200/auth/login`.
> * Select **"Clientes"** tab when signing in as a customer.
> * Select **"Administrativos"** tab when signing in as platform superadmin, store admin, cashier, staff, or provider (this tab does not enforce a role and routes automatically based on database credentials).
